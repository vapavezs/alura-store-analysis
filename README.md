# Alura Store – Análisis de ventas

## Objetivo
Analizar ventas, rendimiento y reseñas de 4 tiendas de Alura Store para identificar la menos eficiente y presentar una recomendación final basada en los datos. 

## Herramientas
- Python
- Pandas
- Matplotlib
- Google Colab

## Estructura del Proyecto
- data/raw: odataset original
- notebooks: notebook para el análisis
- figures: gráficas generadas
